# Overview


### ELEGANCE framework
* Output guidance: AV-TSE with linguistic constraints, where both PLM and PSLM will be utilized during training with an adapter to align the latent semantic space.
* Intermediate guidance: AV-TSE with linguistic prediction, jointly modeling the AV-TSE task and the acoustic-informed LLM next-token prediction (NTP) task. Empower AV-TSE with linguistic forecasting ability with NTP loss.
* Input guidance:  AV-TSE with linguistic prior. The LLM guidance and zero embedding will be added as input features in an interleaved way. The goal is to reduce over-reliance of the AV-TSE model on transcripts, which are not available during inference.
